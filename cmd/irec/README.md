# irec - Image RECovery service
Сервис для восстановления локализованых изображений datamatrix.

## Структура сервиса восстановления
```
        +---------------+    +------+    +---------------+
        |               |    |      |    |               |
Вход -> | Предобработка | -> | Ядро | -> | Постобработка | -> Выход
        |               |    |      |    |               |
        +---------------+    +------+    +---------------+
```

## Этапы обработки
1. **Предобработка** - изображение приводится к ЧБ, а пиксели к диапазону [0, 1]
2. **Ядро** - UNet++ убирает дефекты изображения, строя ЧБ маску datamatrix
3. **Постобработка** - Улучшение качества маски

На данный момент постобработка работает **ТОЛЬКО** в [train](../cmd/train).
